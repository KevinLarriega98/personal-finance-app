# Personal Finance

A responsive personal finance dashboard for tracking income, expenses, balance, and day-to-day transactions.

## Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## MVP features

- View current balance, total income, and total expenses
- View and filter transactions by type or category
- Add, edit, and delete transactions
- Responsive layout for mobile and desktop

## Run locally

```bash
npm install
npm run dev
```

To check the project:

```bash
npm run lint
npm run build
```

The application currently uses local mock data and does not persist changes between page reloads.
